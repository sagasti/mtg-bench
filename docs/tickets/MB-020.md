# MB-020: Missing prompt templates render silently as empty

- **Status:** done
- **Severity:** low
- **Area:** prompts
- **Source:** harness code review (Fable), 2026-10-02; top findings re-verified in code and run artifacts

## Problem

`render.ts:67-74` `readPrompt` returns "" for a missing file and resolves against `process.cwd()`. A new prompt version missing a file, or running from another directory, silently drops prompt sections.

## Suggested fix

- Throw on a missing template; resolve paths from the package root.

## Resolution

On `fix/llm-layer` (91bc32c): templates resolve from the package's `prompts/` (`promptFile` in `render.ts`, also used by
`check`), and a missing template throws. Optional templates are still probed with `hasPrompt`. The run-snapshot copy in
`src/tournament/run.ts` and `match.ts` still resolves `prompts/` from the working directory (it fails loudly if missing);
it could use `promptFile` too.
