# MB-025: --pools-from accepts an incomplete draft log

- **Status:** open
- **Severity:** medium
- **Area:** re-run
- **Source:** tournament pipeline review (Fable), 2026-10-02; reproduced on the mock engine, key claims re-verified in code

## Problem

`resume.ts:58-62` only checks that a seat has at least one pick. A source that crashed mid-draft (an `InfraError` in `runDraft` isn't caught) gives every seat a short pool; reproduced with 20-card pools, which deckbuild silently padded with basics.

## Suggested fix

- Require exactly `packs × packSize` picks per seat (from the source `config.json`) and a completed draft in the source.
