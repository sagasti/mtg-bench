# MB-040: Drafting and playing skill aren't separated

- **Status:** open
- **Severity:** medium
- **Area:** methodology
- **Source:** split from MB-012, 2026-10-02

## Problem

A seat's rating mixes how well it drafts and builds with how well it plays: a good pilot with a weak deck and a weak pilot with a strong deck can rate the same. Published results can't say which skill a model has.

## Suggested fix

- Play-only condition: every seat plays the same fixed decks (e.g. a pod's decks rotated through all seats, via `--decks-from` with seats permuted), so differences are play skill.
- Draft-only condition: a fixed strong pilot (forge-ai) plays every seat's drafted deck against every other, so differences are deck quality.
- Report both next to the full-pipeline rating.
