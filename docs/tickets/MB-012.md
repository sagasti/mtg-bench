# MB-012: Missing pieces for defensible published results

- **Status:** done
- **Severity:** medium
- **Area:** methodology
- **Source:** architecture & methodology review (Fable), 2026-10-02; key claims re-verified against run artifacts

## Problem

Present: versioned prompts, per-decision provenance, provider-reported cost, deterministic bot pods, re-run from saved decks/pools. Missing: a pre-registered event spec with its hash in `run_start`; a published noise floor (MB-001); ablations isolating harness effects (stops, knowledge level, study, notes, think/no-think); a draft/play decomposition (fixed strong pilot plays every seat's deck; LLMs play fixed decks); a human baseline; a held-out cube (MB-009); stated exclusion rules for seats with high forfeit/fallback/API-error rates and for censored matches (MB-006).

## Suggested fix

- Treat this as the umbrella checklist; split into tickets as each is picked up.

## Resolution

2026-10-02 (branch `fix/methodology`). Every item is now done or its own ticket:
- **Pre-registered spec.** `configHash` (src/config.ts): SHA-256 of the effective config with keys sorted (event, seats, pricing, engine settings), leaving out where it runs (`outputDir`, `forgeRes`, the engine's forgeDir / forgeJar / bridgeJar / java / javaOpts; the run id isn't in the config). Recorded in `run_start.configHash` and config.json (events and `match`), shown under report.md "Versions"; `check` prints it. `run --expect-hash <h>` (≥ 8 hex digits) refuses to start when the effective config, after `--pods` / `--engine`, hashes differently. Checked: a config pre-registered with `check`, then run with `--pods 2`, was refused; run as registered, it ran and recorded the hash. Not covered: the `--decks-from` / `--pools-from` source (recorded separately in `run_start.source`).
- **Exclusion rule for unreliable seats.** A seat whose forfeits (harness and bridge) + fallbacks + API errors exceed `event.maxFailureRate` (default 0.05) of its decisions is listed under "Excluded from the leaderboard", below the ranked table, with its rating, CI and failure counts kept; its games still count for its opponents. `report --max-failure-rate` overrides the threshold; summary.json `excluded`. Checked with an echo seat answering invalidly 60% of the time: 58 forfeits in 526 decisions (11.0%), listed apart.
- **Censored matches** (MB-006): replayed once, then censored, as a stated policy (docs/ANALYTICS.md).
- **Noise floor**: MB-001 (owner running it). **Ablations**: MB-039. **Draft/play decomposition**: MB-040. **Human baseline**: MB-041. **Held-out cube**: MB-042 (with MB-009).
