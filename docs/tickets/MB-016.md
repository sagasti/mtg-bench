# MB-016: Malformed submit_decision calls are coerced to choice [] and accepted when min is 0

- **Status:** open
- **Severity:** medium
- **Area:** harness / validation
- **Source:** harness code review (Fable), 2026-10-02; top findings re-verified in code and run artifacts

## Problem

`llm.ts:133-136` maps a missing or non-array `choice` (e.g. `"c12"`, or unparseable tool arguments from `openai.ts:68`) to `[]`. For min-0 kinds (attackers, blockers, optional costs, targets per MB-013) that validates as a deliberate "none" with `invalidAttempts: 0`.

## Suggested fix

- Reject the call as an invalid attempt when `choice` is missing/non-array or the arguments failed to parse.
