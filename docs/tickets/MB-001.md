# MB-001: Pods, not games, are the replication unit; one pod can't separate models

- **Status:** open
- **Severity:** high
- **Area:** methodology
- **Source:** architecture & methodology review (Fable), 2026-10-02; key claims re-verified against run artifacts

## Problem

A seat keeps one drafted deck for every game of a pod, so its games are correlated through the deck. Identical bots differ by 300+ Elo within one pod (`full-llm-1`: forge-ai-2 1889 vs forge-ai-1 1561; `human-bots-9`: 2027 vs 1691). The bootstrap in `src/rating/bt.ts` resamples matches, not pods, so the quoted 95% CIs (±200–280 Elo) are still too narrow for model-vs-model claims. All configs use `pods: 1`.

## Suggested fix

- Run the all-bot line-up over 5–10 seeds (free) and publish each bot's between-pod rating SD: the benchmark's noise floor.
- Report per-pod ratings and bootstrap over pods (or fit BT with a per-(seat, pod) random effect).
- Size real events from the noise floor (rough estimate: ~20 pods to resolve ~100 Elo).
