# MB-050: Mixed-zone target lists include section headers as selectable options

- **Status:** open
- **Severity:** low
- **Area:** bridge
- **Filed:** 2026-10-02

## Problem

Source: fix/lsv-hangs agent report (2026-10-02). Forge's mixed-zone target dialog lists header strings such as "--CARDS IN GRAVEYARD:--" among the choices; the driver offers them as options, so a bot or LLM can waste a pick on one. Nothing is corrupted (the pick does nothing and is re-asked), but it costs attempts and can end in a forfeit.

## Suggested fix

- Filter header entries (non-entity strings) out of target/list choices in `InputDriver`/`AgentGuiGame`; add a fixture to the conformance suite if a cube card reproduces it.
