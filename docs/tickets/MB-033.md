# MB-033: Reveals are turned into agent decisions

- **Status:** open
- **Severity:** medium
- **Area:** bridge / analytics
- **Source:** Java bridge review (Fable), 2026-10-02; traced in the bridge and Forge 2ccbbb01; key claims re-verified

## Problem

`AbstractGuiGame.reveal` calls `getChoices(message, -1, -1, items)`; `AgentGuiGame.getChoices` asks the agent "choose 0 to N" and discards the answer. Each reveal costs a model call and counts as an agent `choose_cards` decision.

## Suggested fix

- Override `reveal` in `AgentGuiGame` as a no-op; optionally add the revealed cards to the information the agent sees.
