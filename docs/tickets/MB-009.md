# MB-009: Cube contamination; bot-only computed hints; coarse decision kinds on the human path

- **Status:** open
- **Severity:** medium
- **Area:** information policy
- **Source:** architecture & methodology review (Fable), 2026-10-02; key claims re-verified against run artifacts

## Problem

Hiding the cube name buys little: DeepSeek's Pauper-cube brief identifies the cube's archetypes from the list, and `search_cube` returns it. Bots get computed hints (`incomingLethal`, `blockerSurvives`) that LLM seats don't, by design but unstated next to ratings. `AgentGuiGame.getChoices` reports discard, London-mulligan bottom, scry and play/draw as `choose_cards`, so the by-kind tables mislabel them.

Tournament review adds: the coin-toss play/draw choice is recorded as `choose_cards` on the human path (5 in `human-bots-9`, 0 `play_draw`).

## Suggested fix

- Add a held-out or novel cube condition.
- State the bot-hint asymmetry in the report.
- Map Forge inputs to the finer `DecisionKind`s in `src/types.ts`.
