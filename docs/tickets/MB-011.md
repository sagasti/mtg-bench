# MB-011: Cost and wall-clock scale with the slowest, most expensive seat

- **Status:** done
- **Severity:** medium
- **Area:** cost / scale
- **Source:** architecture & methodology review (Fable), 2026-10-02; key claims re-verified against run artifacts

## Problem

`full-llm-1`: one cheap seat, $0.35, ~10M input + 1.1M output tokens, 3h39m. Each round lasts as long as its slowest match; at frontier prices one 8-LLM pod is roughly $0.5–1.5k, and MB-001 suggests many pods are needed.

## Suggested fix

- Per-seat spend/latency budgets that stop a seat (remaining matches marked not played) rather than the run.
- Prefer more pods with fewer rounds (Swiss); reuse expensive drafts via `--decks-from` for play-only replays.

## Resolution

2026-10-02 (branch `fix/methodology`). Seat options `maxSpendUsd` (computed cost: tokens × `pricing`, so the model needs a pricing entry; validated) and `maxP95LatencySec` (p95 of the seat's model-answered decision latency, applied after 20 decisions). `Seat.overBudget()` tracks both as calls and decisions are recorded; the first time it trips it records a `seat_over_budget` event and the seat stays stopped. Before each match (events and `match`), a stopped seat's match is recorded as not played (`MatchResult.notPlayed`: no games, no result, no forfeit, no standings points, not in the ratings); the run goes on. Draft picks and deckbuilds of a stopped seat (a later pod) are rank-bot fallbacks with `error: "over budget: ..."`, since the pod still needs eight drafters. A match already under way finishes, so a seat can overshoot by about one match. report.md / summary.json list the matches not played per seat and why. Checked on the mock engine with an echo seat at `maxSpendUsd: 1.5` over 2 pods: it went over after its first match ($1.84), its other 13 matches were not played, its 43 later draft/deckbuild decisions were fallbacks.

Docs: docs/AGENTS.md (seat options, "Budgets stop a seat"), docs/ANALYTICS.md, HANDOFF §6. The second bullet needs no code: Swiss with `rounds` and `--decks-from` replays already exist.
