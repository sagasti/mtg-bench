# MB-026: Derived runs don't check the source matches the new config

- **Status:** open
- **Severity:** medium
- **Area:** re-run
- **Source:** tournament pipeline review (Fable), 2026-10-02; reproduced on the mock engine, key claims re-verified in code

## Problem

`SourceRun` compares seat ids only. A seat re-pointed to another model, a different cube, or `cubeStudy: true` against a source without briefs are all accepted, and the derived run's `run_start` lists the new models while the draft, decks, briefs and notes came from the old ones. Reproduced on the mock engine.

## Suggested fix

- Read the source `config.json`; error (or require `--allow-seat-changes`) when provider/model/cube/packs/packSize/cubeStudy differ.
- Record the source's seat→model map in the derived run.
