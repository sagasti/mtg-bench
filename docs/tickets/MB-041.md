# MB-041: No human baseline

- **Status:** open
- **Severity:** medium
- **Area:** methodology
- **Source:** split from MB-012, 2026-10-02

## Problem

Ratings are relative to the bots and to each other. Without human players on the same scale, a reader can't tell whether a rating means "plays like a beginner" or "plays like a strong drafter".

## Suggested fix

- Let a human take a seat through the same decision interface: a provider that shows the rendered prompt and options (terminal or web page) and returns the human's choice, under the same information rules as LLM seats.
- Run a few pods with human players of known level against the anchors, and report their ratings with the same pod-level CIs.
