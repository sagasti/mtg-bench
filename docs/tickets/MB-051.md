# MB-051: Record the provider's native finish reason on failed calls

- **Status:** done
- **Severity:** low
- **Area:** harness / observability
- **Filed:** 2026-10-02

## Problem

Source: `runs/llm8-lsv-1` round 1: gemini-flash-lite (Google AI Studio) returned seven consecutive empty responses on one decision, aborting the match as an infrastructure error (replayed at the end of the round). The usage row only says "empty response (no content, no tool calls, 0 output tokens)"; OpenRouter also returns `native_finish_reason` (e.g. Gemini's SAFETY / RECITATION blocks), which would show whether this is a content filter triggered by quoted card text (deterministic, so replays fail too) or a transient outage.

## Suggested fix

- Record `native_finish_reason` (and any `error` object) on every usage row and in the failure message.
- If recitation blocks are confirmed, decide policy: e.g. per-provider safety settings where available, or classify a deterministic content block as the seat's failure to answer rather than infra (and document it).

## Resolution

Done 2026-10-03 (`fix/harness`), recording part. Every usage row now carries `nativeFinishReason` (OpenRouter's
`native_finish_reason`, on answered and failed calls) and `providerError` (the provider's `error` object, JSON,
truncated to 500 characters) when the provider sends them, and failed attempts carry `servedBy` when the gateway names
the host (`error.metadata.provider_name`). The failure message itself names the native reason, e.g. `provider error in
HTTP 200 body: empty response (no content, no tool calls, 0 output tokens) (native_finish_reason "RECITATION")`.
Checked offline with a fake fetch (an empty Gemini-style answer with `RECITATION`, in-body 502s, 429/503 bodies).

Policy part: an empty answer whose native reason is a content block (`SAFETY`, `RECITATION`, `PROHIBITED_CONTENT`,
`BLOCKLIST`, `SPII`, `content_filter`, `refusal`), like any empty answer, keeps the 7-attempt limit rather than
MB-054's 20-minute window, so a deterministic block can't stall a match. Whether a confirmed content block should be
charged to the seat (no answer) instead of infrastructure stays open until the next run shows what Gemini's empty
responses actually were.
