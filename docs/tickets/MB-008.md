# MB-008: Same seed means same packs: runs aren't independent replicates

- **Status:** done
- **Severity:** medium
- **Area:** methodology
- **Source:** architecture & methodology review (Fable), 2026-10-02; key claims re-verified against run artifacts

## Problem

Packs and seating derive from `event.seed` (every config ships `seed: 42`); `human-bots-8` and `-9` produced identical ratings. Good for paired comparisons and replays, but two events on the same cube draft the same packs in the same seats, and `bench report a b` pools them as if independent. No config sets `temperature`, so LLM sampling uses provider defaults.

Tournament review adds: seating is shuffled from the pod stream before match seeds are forked, so a `--decks-from` replay gets different Forge seeds than its source (not a controlled replay), while two fresh same-seed runs get identical shuffles and die rolls. Fix: shuffle seating from a dedicated `prng.fork("seating")`.

## Suggested fix

- Document the fixed-pack design; use a seed schedule (base + pod) across events; record the seed per pod.
- Make `report` refuse to pool runs with identical (cube, seed, pod) unless forced.
- Set and record `temperature` per seat.

## Resolution

2026-10-02 (branch `fix/tournament`). Seating is shuffled from `prng.fork("seating")`, so it no longer advances the pod stream: a `--decks-from` / `--pools-from` replay now gets the same match seeds as its source (this changes the seating a given seed produces compared with earlier runs). `pod_start` records `seed` and `draftSeed` (the source's draft seed in a derived run); `run_start` records `seed` and each seat's `temperature` when the config sets one. `report` and `rate` refuse to pool runs that share a pod with the same cube, draft seed and pod index unless `--allow-same-seed` is given; a run and its own replay count as sharing. The fixed-pack design and the advice to give each event its own seed (base + event index) are in docs/ANALYTICS.md "Seeds and independent replicates" and HANDOFF.md §6. Verified on the mock engine: two seed-7 runs, and a run with its `--decks-from` replay, are refused; `--allow-same-seed` merges them; seeds 7 and 8 pool without complaint.

Setting `temperature` per seat in the configs belongs to the agent/config work (MB-004 area); this ticket only records it.
