# MB-021: Bootstrap clusters collide when merging runs

- **Status:** open
- **Severity:** low
- **Area:** ratings
- **Source:** harness code review (Fable), 2026-10-02; top findings re-verified in code and run artifacts

## Problem

`outcomes.ts` clusters by `matchId`, which repeats across runs with the same seats (`p0-r1-X-vs-Y`), so `report runs/a runs/b` resamples two independent matches as one unit.

Tournament review confirms: `human-bots-8` and `-9` share 28/28 matchIds; 51 of 52 runs use `seed: 42`.

## Suggested fix

- Cluster by `runId + matchId`.
