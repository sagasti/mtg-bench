# MB-039: No ablations isolating harness effects

- **Status:** open
- **Severity:** medium
- **Area:** methodology
- **Source:** split from MB-012, 2026-10-02

## Problem

A rating measures a model inside our harness: priority stops, knowledge level and tools, cube study, match notes, the scratchpad, thinking on or off. None of these has been varied with the model held fixed, so we can't say how much of a rating (or of a gap between two models) comes from the harness settings rather than the model.

## Suggested fix

- For one cheap model, run paired events that change one setting at a time (`knowledge`, `cubeStudy`, `carryNotes`, prompt version with/without match notes, `priorityStops: all`, reasoning on/off), same seeds, with the anchors as the common scale.
- Per-seat settings (reasoning) can share an event as two seats; event-level ones need separate events (see docs/AGENTS.md "Ablations").
- Report each setting's effect with its pod-level CI (MB-001) and record which settings the headline results use.
