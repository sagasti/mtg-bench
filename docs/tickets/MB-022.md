# MB-022: Card reference omits graveyard, exile and stack-source cards

- **Status:** open
- **Severity:** low
- **Area:** prompts
- **Source:** harness code review (Fable), 2026-10-02; top findings re-verified in code and run artifacts

## Problem

`render.ts` `CARD_KEYS` doesn't include `graveyard`, `exile` or `stack[].source`, so at the `oracle` tier the agent gets no card text for spells on the stack or cards in graveyards (flashback, recursion). Same for every seat.

## Suggested fix

- Add those keys to `CARD_KEYS`.
