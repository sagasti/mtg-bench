# MB-019: Tokens of decisions that end in infra errors are missing from the cost tables

- **Status:** open
- **Severity:** medium
- **Area:** analytics
- **Source:** harness code review (Fable), 2026-10-02; top findings re-verified in code and run artifacts

## Problem

`agent.ts:115` throws `InfraError` before `recorder.decision(...)`; `report.ts:30-42` sums tokens and cost from decision rows only. Tokens spent before the failure are in `usage.jsonl` but not in the cost columns. No error has occurred yet in a recorded run, so current totals match.

## Suggested fix

- Record the decision row (with `error`, `infraError`) before throwing, or compute cost from `usage.jsonl`.
